## Neovim configuration


Install neovim and treesitter-cli
```bash
sudo pacman -S neovim tree-sitter-cli
```

Install go - required for efm-langserver
```bash
sudo pacman -S go
```

Needed for luasnip
```bash
sudo pacman -S lua-jsregexp
```

General utilities
```bash
sudo pacman -S git ripgrep fzf fd
```
